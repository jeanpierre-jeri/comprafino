# UI component audit — Milestone 19A.1 correction

This review uses the current working components, `base-nova`, `@base-ui/react` 1.8.0, Lucide and Tailwind 4. It does not authorize shopping sync or backend changes. The pre-existing staged 19A.1 work is preserved; the correction adds unstaged changes without altering staging.

## Official references and source

Reviewed the current official **Base UI** variants of [Toast](https://ui.shadcn.com/docs/components/base/toast), [Dialog](https://ui.shadcn.com/docs/components/base/dialog), [Dropdown Menu](https://ui.shadcn.com/docs/components/base/dropdown-menu), [Avatar](https://ui.shadcn.com/docs/components/base/avatar), [Button](https://ui.shadcn.com/docs/components/base/button) and [Select](https://ui.shadcn.com/docs/components/base/select).

`pnpm dlx shadcn@latest docs ...` and `view @shadcn/...` supplied the documentation/source through CLI 4.21.2 in a temporary reference project with the same base-nova configuration. Direct execution inside packages/ui could not resolve the existing unused hooks alias; that repository configuration was not changed. No registry overwrite was run. Official source was integrated with monorepo aliases, real Lucide icons, Spanish close labels and existing semantic tokens. No Radix or new primitive package was installed.

The correct Base UI feedback API is `toast.add({ type: "error", title: ... })`, backed by `Toast.createToastManager`, Provider, Portal, Viewport and the official stacked-toast renderer. Sonner was a wrong-stack choice here and has been removed. Toasts inherit theme tokens through the portal; they need no separate theme observer/provider.

## Dialog migration details

Both login and shopping dialogs now compose official Dialog, DialogContent and DialogTitle. Login adds DialogDescription. Controlled open state and `onOpenChangeComplete` defer parent unmount/focus return until exit finishes. `initialFocus` preserves Google-button/quantity focus; Base UI handles trapping, Escape and outside dismissal. A real DialogClose with Spanish accessible name remains available, with the established 44px target.

The old native showModal/context/listener/timer implementation is deleted. Existing 180ms entry/140ms exit keyframes are retained and driven by Base UI open/ending attributes; the existing reduced-motion policy makes them immediate. Styling retains mobile width/height bounds, theme tokens and backdrop opacity. Shopping form semantics and list storage are unchanged. Content-origin drag-to-backdrop dismissal and all existing close/focus behavior are verified by the controlled browser suite.

Tests use real persisted Better Auth sessions in explicit owned disposable PostgreSQL schemas and local provider/transport fixtures. The auth backend, Google scopes, migrations and public evaluation API are unchanged. Screenshots remain ignored Playwright artifacts, with no permanent visual snapshot infrastructure added.
